# パンバトル 3D 試遊版

iPhoneを縦に持ち、軽く振って攻撃、左右に傾けて回避するCPUとの1対1ゲームです。食パン・フランスパン・クロワッサン・メロンパン・カレーパン・クリームパンの6種類から選べます。

試遊URL: https://sryusukeh-hue.github.io/panbattle-play/

Safariで開き、「食卓で勝負する」→「動きの利用を許可する」→構え位置の調整→パン選択→練習へ進みます。証明書の追加やアプリのインストールは不要です。1試合60秒以内。結果で回避・反撃の成績を同じ条件の自己ベストと比較できます。

**iPhoneでの操作感と性能を確認中の試遊版です。** 最初は軽い動きで練習してください。センサーを利用できない場合は「補助操作で遊ぶ」からタッチ操作を選べます。

設定の「攻撃の出やすさ」と「回避のしやすさ」は別々に調整できます。以前の操作感度は両方へ引き継ぎます。急いで傾けたときの誤攻撃を抑える判定と、予告・回避・反撃の音や表示を追加しました。音は設定からオンにできます。

**ひっさつ（必殺技）**：攻撃を当てる・回避するとゲージがたまり、満タンで「ひっさつ」ボタン（キーボードはX）から各パンの必殺技を出せます。食パン「爆熱ギガトースト」、フランスパン「雷光バゲットブレイカー」、クロワッサン「三日月トルネード」。CPUの必殺技も赤い予告を見て横へ避けられ、避ければ反撃のチャンスです。練習の4段階目で試せます。実機では、左右へ素早く避ける動きと、避けた直後の軽い振りを練習で確かめてください。

CPUの強さは「やさしい・ふつう・つよい」から選べます。「つよい」は連打を見切って避け、空振りに反撃してくるので、予告を見て避けてから反撃すると勝ちやすくなります。決着時のK.O.演出とリプレイ、ダメージ数値、BGM、試合ごとのスコアとランク（S〜C）、次に意識するコツと該当する練習への直行ボタンを追加しました。BGMは設定から切り替えられます。

**新しい3つのパン**：メロンパン（回避でゲージが早くたまる。必殺「ころころメロンローラー」はその場に居残る）、カレーパン（一撃が最大。必殺「二度揚げカレーボンバー」は二拍）、クリームパン（空振り後の戻りが最速。必殺「ふわっとクリームパーン」は横に払う）。選択画面で相手の必殺の避け方も確認できます。

**パンの顔**：3つのパンに、ちょっと変でかわいい顔が付きました。お人よしの食パン、気取り屋のフランスパン、いたずら好きのクロワッサン。予備動作・攻撃・被弾・回避・反撃・必殺技・疲れ・勝ち負けで表情が変わり、まばたきや相手を目で追う動きもあります。自分のパンの顔は、体力バー横の顔アイコンと結果画面で見られます。動きを減らす設定の端末では、まばたきとよそ見を止めます。

## 開発・検証

Node.js 20.19以上を使用します。

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run check:size
npm run test:browser:install
npm run test:e2e
npm run dev -- --host 127.0.0.1 --port 4183
```

ローカルURLは `http://127.0.0.1:4183/panbattle-play/`。キーボード操作はSpace/Zで攻撃、矢印/A Dで横移動、Xでひっさつ、Escapeで一時停止です。

GitHub Actionsで検証後、`dist-3d/`をPagesへ公開します。配布上限は5 MiB。検証用状態制御は開発時の`?test=1`のみで、配布物には入りません。

このリポジトリは3D試遊版の公開用です。制作元のBlenderファイルやLAN接続用の証明書・秘密鍵は含めていません。パンのモデルは制作者提供のGLBを使用し、読み込んだ複製に動きを付けています。保存は端末内の`panbattle.3d.v1`を使用します。
